# 무던한 지도 (Calm Map)

발달장애·감각 민감 아이와 나가기 전에, 폰이 **지금 여기 소리의 종류**를 알아듣고 서울 120곳이 **언제 덜 붐비는지** 알려 주는 웹 시제품입니다.

- 체험: https://kangraemin.github.io/calm-map/ (폰 브라우저 권장, 마이크 없이도 '합성 시연음'으로 해 볼 수 있음)
- 2026 AI 라이프 솔루션 챌린지 출품작 — 2026 AI 라이프 아이디어 챌린지 수상 후보작 8번 「무던한 지도(Calm Map)」 구현

## 무엇이 AI인가
| 부분 | 방법 | 어디서 도나 |
|---|---|---|
| 소리 종류 알아듣기 | Google YAMNet(AudioSet 521종) → 경보음·사람 큰 소리·기계음·웅성임/음악 묶음, 안내방송·돌발음 규칙 | 폰 브라우저 안(MediaPipe Tasks Audio). 원음 저장·전송 없음 |
| 덜 붐비는 시간 예측 | 서울 생활인구(행정동) → 주요 120장소 영역 넓이 비율 배분 → LightGBM(장소×요일×시간×공휴일) | `model/train.py`, 결과 `site/data/forecast.json` |
| 아이별 맞춤 | 아이가 힘든 소리 8종을 보통·민감·매우 민감으로. 매우 민감한 소리가 잡히면 다른 값과 상관없이 '주의' | 폰 안(localStorage) |

## 검증 (마지막 14일 7/18~7/31, 120장소 × 14일 × 24시간 = 40,320칸)
| 방법 | MAPE | 4단계 맞춤 | 실제보다 낮게 안내 | 붐빔 잡아냄 |
|---|---|---|---|---|
| LightGBM | 3.31% | 78.5% | 6.0% | 88.8% |
| 지난주 그대로(계절 나이브) | 4.36% | 76.4% | 9.7% | 80.7% |
| 요일·시간 평균 | 4.31% | 73.9% | 5.2% | 91.2% |
| **앱에 쓰는 값 max(LightGBM, 평균)** | 4.43% | 72.2% | **2.5%** | **95.3%** |

부담을 낮게 잘못 안내하지 않는 것이 첫 원칙이라(제안자 답변서), 정확도를 조금 내주고 과소 안내를 2.5%로 줄인 값을 씁니다.

## 규칙 (제안자 사전질의 답변서 그대로)
- 종합 = 하위 값(혼잡·소리 크기·소리 종류/돌발성·밝기)의 최댓값. 평균으로 상쇄하지 않음.
- 0~39 무던함 · 40~69 보통 · 70~100 부담 높음.
- 소리·빛 정보가 없으면 종합은 '정보 부족', 혼잡만 따로.
- 잰 시간 외에는 혼잡 모양으로 보간한 '추정'(빗금). 추정만으로 무던함 추천 안 함.
- 밝기는 센서가 열린 기기에서만, 깜빡임은 '미측정'.
- 돌발 = 최근 1분 LA90 대비 1초 안에 10dB 이상 상승. 안내방송 추정 = 차임 뒤 말소리 또는 급히 커진 말소리.

## 다시 만들기
```
pip install lightgbm pandas numpy pyshp shapely
python model/train.py <생활인구 CSV 폴더> <121장소 shp(확장자 없이)> <행정동 geojson>
python scripts/make_demo_sounds.py   # macOS(say) 필요
python scripts/fetch_live.py         # SEOUL_API_KEY 있으면 실시간 혼잡도
python -m http.server -d site
```
